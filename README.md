# Ash Bell · 燼界：無聲之鐘

Canvas 2D 暗黑動作遊戲。六名異族角色對抗人類遠征軍，四大關十二張地圖，成長到 LV.30。

開啟 `index.html` 即可遊玩，沒有任何外部依賴。

- 電腦：左鍵移動／點敵人攻擊，右鍵技能；WASD 移動、Space 閃避、1/2/3 施放、Q 換招、L 技能樹、I 裝備
- 手機：搖桿移動、長按攻擊、拖曳技能瞄準後放開施放
- 每張地圖要找到並破壞三個封印，之後地圖上方會開啟光柱，走進去首領才會現身

這是產出的可遊玩版本，素材已壓到 1024px 以便手機載入。原始專案另存，請不要在這裡改程式。

原創作品，非 Blizzard 官方遊戲。
